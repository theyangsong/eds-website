# Design Tokens

EverGreen Website tokens are authored in `packages/tokens/spec/` and built to CSS via `pnpm build:tokens`.

## Token systems

| System | Spec | CSS output |
|--------|------|------------|
| Scale | `spec/scale/` | `--spacing-*`, `--radius-*`, `--stroke-*`, `--icon-*` |
| Typography | `spec/typography/` | `--eds-*`, `--eds-family-sans` |
| Text (showcase) | `spec/text/` → `apps/showcase/src/styles/text-styles.css` | `.typography-display`, `.typography-body-medium`, … |
| Color | `spec/color/` | `--text-*`, `--material-*`, `--box-*`, `--event-*` |
| Effect | `spec/effect/` | `--effect-shadow-*`, `.effect-molde-level`, `.effect-flotation-box`, … |

Effect mirrors Color: `effect/themes/light/` and `effect/themes/dark/` each contain `base.css` (variables) + `semantic.css` (classes). Light values resolve from the light color palette; dark from dark.

Import order: `scale → typography → color → effect` (text style **classes** are showcase-only)

```css
@import '@eds/website-tokens';
```

## Usage in CSS Modules

```css
.myComponent {
  color: var(--text-base-primary);
  background: var(--material-card-moderate);
  padding: var(--spacing-4);
  border-radius: var(--radius-md);
  font-size: var(--eds-body-medium-size);
  line-height: var(--eds-body-medium-line-height);
}
```

Or use text utility classes:

```html
<p class="typography-body-medium">Body text</p>
```

## Figma sync workflow

Linked file: [EverGreen Design System (WebSite)](https://www.figma.com/design/RSjA0dgInAwyPjE1MIinH7/EverGreen-Design-System--WebSite-)

Variable collections in Figma:

- **Color System** — Text, Stroke, Material, Primitives
- **Scale System** — Primitives
- **Typography** — Display, Headline, Title, Body, Footnote

1. Open the Figma file
2. Compare variables with `packages/tokens/spec/*.json`
3. Update spec JSON files
4. Run `pnpm build:tokens` to regenerate CSS

Check sync status: `pnpm sync:tokens`
